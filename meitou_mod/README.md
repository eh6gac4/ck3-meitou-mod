# 名刀 Mod 試作版 v0.5

髭切・膝丸・三日月宗近・童子切安綱・大包平を入手できる物語を追加します。前四振りはCK3本体の宝物生成処理を使い、大包平だけをMod独自の宝物として生成します。日本を旅行する成人プレイヤーが州に入るたび、未入手で再発待ち期間中ではない刀ごとに0.25%の確率で物語が始まります。領地を持たない冒険者も対象です。

867年開始から全五振りが登場します。1066年以降に開始したゲームでは、本体の初期配置との重複を避けるため、Mod側の四振りの入手経路を無効にします。867年開始のゲームでは、年月が1066年を越えてもModの入手経路を維持します。作刀年、人物の生没年、呼称や伝説の成立時期は867年開始時の登場条件にしていません。

## v0.5：デバッグメニュー

1. CK3の起動オプションに `-debug_mode` を付けて起動します。
2. 本MODを有効にした検証用セーブを開きます。
3. 「決断」の「名刀イベントのデバッグ」を実行します。
4. 刀を選び、導入・試練・成功の文章・失敗の文章を開きます。

コンソールからは `event meitou_debug.0001` でも同じメニューを開けます。デバッグモードが必要です。Steamではゲームのプロパティの起動オプションに指定します。メニューは人間プレイヤー専用で、通常モードでは決断と試練内のデバッグ選択肢が非表示になります。

| 操作 | 動作 |
|---|---|
| 導入から試す | 旅行中・日本国内・180日待機の条件を一回だけ省略します。入手済みの刀には使えません。 |
| 試練を開く | 通常の能力判定、支払い、辞退を試せます。入手済みの場合の終了処理も確認できます。 |
| 成功／失敗の文章だけを見る | 結末の表示だけを確認します。宝物・入手記録・金・ストレスは変更しません。 |
| ［デバッグ］入手成功を実行する | 試練内の専用選択肢。確率判定なしで宝物を生成し、入手記録を付け、成功の結末を開きます。金は不要です。 |
| ［デバッグ］失敗とストレス増加を実行する | 試練内の専用選択肢。確率判定なしで、その刀の失敗時ストレスを付け、失敗の結末を開きます。 |
| 再発待ちのリセット | 確認画面の後、操作中の人物の180日待機だけを解除します。世界共通の入手記録は保持します。 |
| 検証用に100金を追加する | 最初の刀選択メニューから所持金を100増やします。 |

**入手済みの刀を繰り返し試す場合は、入手前のセーブを読み込んでください。** リセットは宝物や入手記録を削除しません。金・ストレス・能力や他の人物の待機期間も元には戻りません。

デバッグ用の導入許可は、導入が開いた時点で消費します。開けなかった場合でも1日で失効し、通常モードでは許可が残っていても条件を省略しません。通常の旅行からの抽選にはこの許可を使いません。

繰り返し試すには、イベントを最後まで閉じ、決断からメニューを開き直します。入手済みの刀を再試行する場合は、入手前のセーブに戻します。強制成功・失敗は結末と効果の確認用です。実際の確率判定や能力値の境界を確認する場合は通常の選択肢を使ってください。

五振りすべてのデバッグ導線と、通常モード・AIからの非表示、入手済み時のガード、刀別リセットを独自の解析・効果シミュレーションで検査しています。CK3本体での表示・動作は未確認です。

## 刀ごとの物語

各刀に「導入 → 試練 → 成功または失敗」の連続イベントがあります。導入と試練では辞退もできます。歴史上の人物を登場させず、架空の守り手から刀を譲り受けます。五振りの物語イベントには主人公と守り手の立ち絵を表示し、導入・試練・成功・失敗で表情を変えます。

| 刀 | 物語 | 能力を使う二つの方法 | 確実に進める方法 | 失敗時 |
|---|---|---|---|---|
| 髭切 | 鬼切りの伝承を聞き、夜の橋で旅人を守る | 武勇で立ち向かう／外交で通行を取り持つ | 夜警と灯火に45金 | ストレス＋25 |
| 膝丸 | 傷んだ由緒書から「膝丸」と「薄緑」の記憶を引き継ぐ | 学識で記録を読む／外交で家人の信頼を得る | 書写と保管に40金 | ストレス＋20 |
| 三日月宗近 | 刀の鑑賞会で、名声に惑わされず刃文を見極める | 学識で鑑定する／外交で美しさを伝える | 手入れと鑑賞の場に80金 | ストレス＋15 |
| 童子切安綱 | 酒呑童子の物語になぞらえ、鬼を名乗る山賊を退ける | 軍事で攻める／策略で宴の隙を突く | 案内人と護衛に60金 | ストレス＋30 |
| 大包平 | 家宝を手放す家から、刀を守る責任を託される | 管理で保存計画を示す／軍事で扱いを示す | 蔵と屋敷の修繕に60金 | ストレス＋20 |

能力を使う選択肢は、対応する能力が12以上なら成功率80%、12未満なら45%です。試みるための金は不要です。費用を負担する方法は所持金が足りる場合のみ選べ、確実に入手できます。能力と資金が乏しくても辞退できます。

導入の表示から180日間、同じ人物には同じ刀の物語が再発しません。辞退・失敗の場合は、その期間後に再挑戦できます。刀ごとの抽選は独立しているため、別の刀の話が同じ移動で始まることはあります。

刀の付与と世界共通の入手記録は、試練に成功した時点で処理します。入手済みなら以後の発見対象から外れます。選択肢の表示条件だけでなく効果実行時にも入手記録と支払い能力を再確認します。途中で別の人物が先に入手した場合などは、刀や費用を動かさず共通の終了イベントへ進みます。1066年以降に開始したゲームでは、本体の四振りと重複しないよう導入と報酬を抑止します。複数プレイヤーでの実動作は未検証です。

続きのイベントはその場で進み、移動中や日本国内という条件を再要求しません。旅の終了で結末だけが発生しなくなることを避けるためです。童子切を「借りる」描写は物語上の表現で、実際の宝物は成功した時だけ生成します。各刀の守り手は立ち絵用のキャラクターとして生成し、同じ物語の後続イベントに引き継ぎます。デバッグで途中のイベントだけを開いた場合も守り手を生成します。守り手は辞退時や結末の終了時にゲームから静かに退場させます。ほかの架空の同行者は生成しません。

## 史料と創作の区別

| 刀 | 参照した来歴・特徴 | 今回の創作部分 |
|---|---|---|
| 髭切 | 渡辺綱が橋で鬼の腕を断ったとする伝承。髭切・鬼切という呼称 | 老武者、橋の通行妨害、夜警の手配、譲渡 |
| 膝丸 | 『薄緑太刀伝来』に記される満仲の二振りと、義経の所持時の「薄緑」という名 | 傷んだ由緒書を抱えた一家と、記録の継承による譲渡 |
| 三日月宗近 | 三条宗近の作、三日月形の刃文と名前の由来 | 鑑賞会、主人による問い、刀の管理を条件とする譲渡 |
| 童子切安綱 | 伯耆安綱の作、頼光と大江山の酒呑童子を結びつける伝説 | 鬼を名乗る人間の山賊、刀の貸与、討伐後の譲渡 |
| 大包平 | 通常の包平作と異なる堂々たる姿と長銘、後世に池田家に伝来した家宝 | 架空の家の財政難、保存・運用の試問、支援と継承 |

所蔵機関による刀剣の年代評価と、その刀に結びつく人物の伝承は同じものではありません。例えば大覚寺所蔵の薄緑（膝丸）は公式紹介で鎌倉時代・13世紀とされます。また、e国宝では酒呑童子伝説は室町時代に成立したと考えられる旨が説明されています。本MODではこれらを年代を越えて語られる物語として取り入れます。超自然的な力を史実やゲーム上の確定事実にはしていません。

## 導入と更新

Paradox LauncherでローカルModを作成し、そのModフォルダに本フォルダの中身をコピーしてください。All Under Heavenの日本刀素材を参照しています。

旧版のファイルが残らないよう、既存のModフォルダをバックアップしたうえで入れ替えてください。以前の試験用決断ファイルが残るのを防げます。イベントを開いたまま更新せず、事前にセーブを控えてください。

v0.3までの刀IDと世界共通の入手記録を維持しています。既存セーブに生成済みの旧Mod版宝物は、自動で本体版に変換・削除しません。旧版を使った1066年以降のセーブでは、すでに重複している宝物も残ります。更新前にセーブを控えてください。

## 宝物の効果

- 髭切：本体と同じ武勇＋2、月間威信＋0.2、恐怖の減少を軽減
- 膝丸：本体と同じ武勇＋2、月間威信＋0.2、伯領支配度の成長＋15%
- 三日月宗近：本体と同じ武勇＋2、月間威信＋0.2、騎士の効率＋10%
- 童子切安綱：本体と同じ武勇＋2、月間威信＋0.2、月間王朝の威信＋5%
- 大包平：武勇＋3、騎士の効率＋5%

五振りとも朽ちません。前四振りは本体と同じ外観・希少度・効果・来歴の生成処理を使います。867年のゲームで獲得しても、本体の生成処理にある950年などの来歴が付くため、ゲーム内表示は未確認です。大包平は既存の日本刀素材を使うMod独自の宝物です。

## 検証

ゲーム内動作は未確認です。添付の開発用ソースでは、プロジェクト直下から `python -m unittest discover -s tests -v` で検査できます。配布用Mod ZIPにはPythonの検査コードを含めません。

検査は独自の限定的なスクリプト解析・効果シミュレーションです。イベント参照、日英の翻訳キー、能力11／12の境界、成功・失敗の確率と結果、所持金の境界、辞退、180日の再発制御、入手済みになった後の古い選択肢を確認します。さらに全スクリプトの構文、立ち絵の人物スコープ、守り手の生成と再利用、旅行時の抽選、宝物の参照先を検査します。CK3のゲームファイルがある環境では背景・アニメーション・刀の画像素材・旅行フック・人物テンプレートの実在も確認します。別の場所にインストールした場合は `CK3_GAME_DIR` に `game` フォルダを指定してください。ゲームファイルがない場合はこの参照テストだけをスキップします。CK3のパーサー、スコープ解決、ツールチップ、画面レイアウトを検証するものではありません。

### ゲーム内の確認手順

1. 867年開始の成人プレイヤーで日本を旅行し、通常の移動から発見が起こることを確認します。
2. 分岐ごとに保存したセーブを戻し、次の導入イベントを呼びます。導入の条件と180日の再発待ちがあるため、同じ人物で連続して試す場合は初回より前のセーブを使ってください。

| 刀 | 導入 | 試練 | 成功 | 失敗 |
|---|---|---|---|---|
| 髭切 | `meitou_travel.0001` | `.0101` | `.0201` | `.0301` |
| 膝丸 | `meitou_travel.0002` | `.0102` | `.0202` | `.0302` |
| 三日月宗近 | `meitou_travel.0003` | `.0103` | `.0203` | `.0303` |
| 童子切安綱 | `meitou_travel.0004` | `.0104` | `.0204` | `.0304` |
| 大包平 | `meitou_travel.0005` | `.0105` | `.0205` | `.0305` |

コンソール例：`event meitou_travel.0001`。表の省略されたIDも同じ名前空間です。共通終了は `meitou_travel.0999`。成功・失敗イベントだけを直接呼んでも、刀やストレスは付与されません。報酬と負担は試練の選択肢で処理します。

3. 各刀で二種類の能力判定、金による解決、導入・試練での辞退を試します。能力11／12、費用の1金不足／ちょうどの条件も比較します。
4. 成功時だけ刀が一振り付与されること、失敗時のストレス、費用の一回限りの支払い、入手後の再発防止を確認します。
5. イベント中に旅行が終了した場合も、続きと結末が表示されることを確認します。
6. 複数プレイヤーが同じ刀の話を進め、一方が先に入手した場合に、もう一方が費用を払わず終了できることを確認します。
7. 日本語と英語で本文の改行、長い選択肢、判定確率と結果のツールチップを確認し、`logs/error.log` の新規エラーを調べます。
